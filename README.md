# 🧠 PhilaCare

- 💬 Compassionate AI conversations
- 😊 Mood check-ins
- 📖 Guided journaling prompts
- 🌿 Self-care suggestions
- ❤️ Positive affirmations

## 🛠️ Built With

- AWS PartyRock
- Generative AI
- Prompt Engineering
